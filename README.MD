# WebForum

Вебзастосунок-форум для тематичних обговорень із модерацією та керуванням ролями.

## Опис проєкту

**WebForum** — форум, де користувачі створюють пости, обирають для них теми, коментують матеріали інших. Модератори стежать за дотриманням правил, адміністратор керує системою.

## Проблема, мета та цільова аудиторія

**Проблема:** обговорення розпорошені між месенджерами та соцмережами, у них важко знайти потрібну тему, а за порушеннями правил ніхто не стежить.

**Мета:** створити зручний і безпечний майданчик для тематичних обговорень з модерацією.

**Цільова аудиторія:** студенти, молодь і всі, хто шукає тематичні спільноти для спілкування.

## Ролі користувачів

- **Гість** — переглядає пости, шукає та фільтрує їх, реєструється.
- **Користувач** — створює пости й коментарі, керує профілем, подає скарги.
- **Модератор** — розглядає скарги, ховає й видаляє контент, блокує порушників.
- **Адміністратор** — керує ролями, темами, правилами та налаштуваннями.

## Основні функції

- реєстрація та вхід;
- створення постів з вибором теми;
- коментування;
- пошук, фільтри та сортування;
- скарги на контент;
- модерація: приховування, видалення, блокування;
- керування ролями й темами.

## Сторінки

Головна, список тем, сторінка теми, сторінка поста, створення поста, вхід і реєстрація, особистий кабінет, панель модератора, панель адміністратора, сторінка помилки.

Детальний опис — у [технічному завданні](docs/technical-requirements.md), сценарії — у [user-scenarios.md](docs/user-scenarios.md).
